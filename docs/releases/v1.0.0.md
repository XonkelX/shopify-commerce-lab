# v1.0.0 — Shopify engineering evidence portfolio

This is the first client-facing release of Shopify Commerce Lab: independent engineering work, not commissioned client results or a production-service claim. A reviewer can start at the [English](https://onielalejofeliz.space/shopify) or [Spanish](https://onielalejofeliz.space/es/shopify) portfolio, inspect seven capability cards, open the [storefront evidence hub](../shopify/README.md), and follow links to source and verification notes.

## Included

- Merchant-configurable Liquid section; advanced variant-aware product page; personalized configurator; case calculator and AJAX cart; three documented theme repairs; performance and accessibility QA.
- Real development-store screenshots, source, test matrices, and accurately labeled captured-state clips. Storefront previews remain password-protected.
- Inventory Sync Monitor source and evidence for real development-store Admin GraphQL and webhooks, PostgreSQL-backed event handling, retries, idempotency, and an embedded dashboard.
- GitHub CI for Theme Check, repository invariants, and app typecheck, lint, unit tests, PostgreSQL migration/integration tests, and build.

## Verification and boundaries

The [published portfolio](https://onielalejofeliz.space/shopify) and its seven images were checked over HTTPS. Portfolio CI and the [Shopify quality workflow](https://github.com/XonkelX/shopify-commerce-lab/actions) passed before release. The theme is unpublished in a password-protected development store. The app was verified through a Shopify CLI development tunnel with a deterministic mock warehouse; it is **not** durably hosted, continuously available, or presented as a production warehouse integration.

This release intentionally avoids a free app host whose cold start could impair Shopify webhooks. Durable deployment, secure hosting configuration, and post-restart auth/GraphQL/webhook/sync checks are deferred until operational hosting is in scope. New live-interaction video is also deferred. The [original strict phase audit](../evidence/strict-acceptance-audit.md) remains open on its own recorded-flow and sequence requirements; this scoped release does not mark those requirements complete.
