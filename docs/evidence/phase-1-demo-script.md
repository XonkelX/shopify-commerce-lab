# Product Comparison Section — 60-Second Demo Script

1. Open the unpublished Shopify preview and show the three-card comparison at desktop width.
2. Point out the shared feature labels, different item values, optional badges, displayed prices, and CTA links.
3. Open the Shopify Theme Editor and select **Product comparison**.
4. Show the section settings for heading, description, columns, image ratio, colors, radius, and spacing.
5. Expand the block list and show that items are addable, removable, hideable, and reorderable.
6. Open one block and show the real Shopify product picker plus image and content overrides.
7. Switch to mobile preview and demonstrate the snap-aligned horizontal card row without page overflow.
8. Close with the source file and the clean Theme Check result.
