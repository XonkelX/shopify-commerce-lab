# Phase 4 Configuration Flow Demo Script

Target length: 60–75 seconds.

1. Open the password-protected [Atlas Personalized Bottle preview](https://oniel-lab.myshopify.com/products/atlas-personalized-bottle?preview_theme_id=155175092398&view=personalized).
2. Show the three-step layout and live bottle preview.
3. Select Navy, then 32 oz. Point out the assigned navy image, $40 Shopify price, availability, summary chip, and updated variant URL.
4. Briefly select Sage with 32 oz to show the real sold-out variant and disabled purchase action, then return to Navy.
5. Submit with an empty personalization field to show required validation. Enter `ONIEL@` to show character validation, then correct it to `ONIEL`.
6. Select Script and show the engraving preview, summary chip, and 5/14 counter update.
7. Enter `Happy trails!`, select gift wrap, and keep quantity at 1.
8. Submit the native Shopify product form.
9. In cart, show Atlas Personalized Bottle, Color Navy, Size 32 oz, $40, and the four properties: Personalization `ONIEL`, Engraving style `Script`, Gift note `Happy trails!`, Gift wrap `Yes`.
10. Open Shopify Theme Editor mobile preview. Show the stacked responsive layout, Product configurator section, merchant settings, and three style blocks.
11. Close on the architecture: real variants drive price/media/availability; custom choices become Shopify line-item properties; no fake dynamic pricing is used.
