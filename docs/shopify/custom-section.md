# Merchant-configurable comparison section

Merchants can update a responsive product comparison without editing Liquid.

![Three-card product comparison section in the unpublished Shopify storefront](assets/custom-section.png)

## What this proves

- Real Online Store 2.0 section schema with editable copy, products, images, layout, and calls to action.
- Addable, removable, and reorderable blocks verified in the Shopify Theme Editor.

## Implementation and verification

- **Shopify stack:** Liquid, section schema, responsive CSS, Theme Editor.
- **Verified:** desktop and mobile layouts, block ordering, add/remove controls, editor settings, and clean Theme Check. [Test notes](../test-results/phase-1-product-comparison.md).
- **Code:** [section](../../theme/sections/product-comparison.liquid) · [homepage template](../../theme/templates/index.json).
- **Additional evidence:** [Theme Editor capture](assets/phase-1-theme-editor.png) · [detailed case study](../case-studies/product-comparison-section.md) · [captured-state clip](assets/custom-section-demo.mp4) (not a live interaction recording).
